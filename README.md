# AWS 無料枠で実現する社内向けツール・サービス・ソリューション

少人数チーム向けに、AWSの無料枠（Always Free および 12ヶ月無料枠）を最大限に活用して構築できる、業務内・業務外のツールやサービスのアイデアをまとめました。

## 🏢 業務内（社内業務・生産性向上）

### 1. サーバーレス社内チャットボット（Slack / Teams / Discord）
日常の定型業務や通知を自動化するチャットボット。
* **ユースケース**: 毎日の朝会のリマインド、勤怠連絡の集約、社内FAQへの自動応答、CI/CDパイプラインの完了通知など。
* **使用するAWSサービス**: Amazon API Gateway, AWS Lambda, Amazon DynamoDB
* **無料枠のポイント**: Lambdaの月間100万リクエスト、DynamoDBの25GBストレージは常に無料。少人数チームのチャットボット程度であれば完全に無料で運用可能です。

### 2. 静的な社内ポータル / ドキュメントサイト
社内マニュアルやオンボーディング資料を管理・共有するサイト。
* **ユースケース**: DocusaurusやHugoなどの静的サイトジェネレータで生成したマニュアルのホスティング。
* **使用するAWSサービス**: Amazon S3, Amazon CloudFront, Amazon Cognito（社内限定アクセス制御用）
* **無料枠のポイント**: CloudFrontの月間1TBのアウトバウンド通信と、S3の5GBストレージを利用。Cognitoは5万MAUまで無料なため、社内認証を簡単に追加できます。

### 3. 日次レポート自動作成・配信システム
各種ツールからデータを集計し、自動でレポートを作成してメール送信するシステム。
* **ユースケース**: 売上データ、システムのリソース使用量、エラーログなどを毎日集計し、朝にサマリーメールを送信。
* **使用するAWSサービス**: Amazon EventBridge, AWS Lambda, Amazon SES, Amazon S3
* **無料枠のポイント**: EventBridgeで定期実行し、Lambdaで処理。SESは無料枠（EC2からの送信か、月間一定数まで）を活用してコストを抑えます。

### 4. 軽量な社内タスク・カンバンボード
チーム内でのタスク管理や進捗共有を行うためのシンプルなWebアプリ。
* **ユースケース**: JiraやTrelloの代わりとなる、チーム専用のカスタマイズされたタスク管理ツール。
* **使用するAWSサービス**: Amazon EC2 (t2.micro / t3.micro), Amazon RDS (db.t2.micro / db.t3.micro)
* **無料枠のポイント**: EC2とRDSの12ヶ月無料枠を活用して、Ruby on RailsやDjangoなどのWebフレームワークを用いた伝統的なシステムを構築できます。

## ☕ 業務外（コミュニケーション・チームビルディング）

### 1. チーム用テックブログ / 趣味ブログ
メンバーが技術的な学びや、休日の趣味について自由に投稿できるブログ。
* **ユースケース**: チームのブランディングや、メンバー間の相互理解を深めるためのナレッジ共有。
* **使用するAWSサービス**: Amazon S3, Amazon CloudFront, AWS Amplify (Hosting)
* **無料枠のポイント**: Amplifyの無料枠やS3/CloudFrontの組み合わせで、高速かつ安価にブログをホスティング。

### 2. 軽量マルチプレイヤーゲームサーバー / 遊び用ボット
終業後や休日にメンバーで遊ぶためのサーバーや、Discord用の面白ボット。
* **ユースケース**: Minecraft（軽量版）やTerrariaなどのマルチプレイサーバー、またはDiscordで「今日のランチガチャ」や「TRPGダイス」を振るボット。
* **使用するAWSサービス**: Amazon EC2 (t2.micro / t3.micro) または AWS Lambda (Webhook駆動のボット)
* **無料枠のポイント**: EC2の750時間/月（1台分）の無料枠を使い、常時稼働のサーバーを構築。重いゲームの場合はスポットインスタンスとの組み合わせも検討。

### 3. イベント・飲み会調整＆出欠管理アプリ
社内イベントやハッカソン、飲み会などのスケジュール調整を行うアプリ。
* **ユースケース**: 複数の候補日から参加者の投票を集め、最適な日程を決定する。
* **使用するAWSサービス**: AWS Lambda, Amazon DynamoDB, Amazon API Gateway, Amazon S3 (フロントエンド)
* **無料枠のポイント**: 完全サーバーレス構成にすることで、利用時のみリソースを消費し、維持費ゼロで運用できます。

### 4. ランダム 1on1 マッチングシステム（シャッフルランチ）
リモートワークでのコミュニケーション不足を解消するため、ランダムにメンバーをペアリングするシステム。
* **ユースケース**: 毎週月曜日に、ランダムに選ばれた2人をSlack上でメンションし、15分の雑談（コーヒーチャット）を促す。
* **使用するAWSサービス**: Amazon EventBridge, AWS Lambda
* **無料枠のポイント**: EventBridgeのcron式トリガーとLambdaによる簡単なスクリプトで、インフラ費用を全くかけずに自動化できます。

## 💡 無料枠利用時の注意点
* **請求アラート（AWS Budgets）の設定**: 意図せず無料枠を超過した場合に備えて、必ず「$1 を超えたら通知する」などの請求アラートを設定しましょう。
* **12ヶ月無料枠と常に無料（Always Free）の違い**: EC2やRDSはアカウント作成から12ヶ月間限定の無料枠です。LambdaやDynamoDBなどは「常に無料」の枠があるため、長期運用を前提とする場合はサーバーレスアーキテクチャ（Lambda + DynamoDB + S3）を積極的に採用するのがおすすめです。
* **不要なリソースの削除**: 使わなくなったEC2インスタンスやNATゲートウェイ、Elastic IPなどは放置すると課金されることがあるため、こまめに削除しましょう。
